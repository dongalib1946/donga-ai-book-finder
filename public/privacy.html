개인정보처리방침

시행일: 2026년 5월 21일

동아대학교 도서관 AI 도서 추천 사이트는 이용자의 개인정보를 최소한으로 처리하며, 서비스 제공에 필요한 범위 안에서만 데이터를 사용합니다.

1. 처리하는 정보

이 사이트는 도서 추천 결과 제공을 위해 이용자가 선택한 질문 응답을 일시적으로 처리할 수 있습니다. 별도의 로그인 기능은 제공하지 않으며, 이름, 학번, 전화번호 등 직접 식별 가능한 개인정보를 필수로 수집하지 않습니다.

2. Instagram API 사용

사이트에 Instagram 피드를 표시하는 경우, Meta Instagram API를 통해 운영자가 연결한 Instagram Professional 계정의 공개 게시물 정보를 불러올 수 있습니다.

  • 게시물 캡션
  • 게시물 이미지 또는 영상 썸네일 URL
  • 게시물 링크
  • 게시 시각

Instagram API 액세스 토큰은 서버 환경변수로 관리하며, 브라우저에 노출하지 않습니다.

3. 도서관 공지 및 외부 콘텐츠

사이트는 동아대학교 도서관 웹사이트의 공개 RSS 또는 공개 페이지 정보를 이용해 최신 공지를 표시할 수 있습니다. 공지 이미지가 있는 경우 이미지 URL만 저장하며, 이미지 파일 자체를 별도로 저장하지 않습니다.

4. 보관 기간

도서 추천 응답은 서비스 화면을 구성하는 동안에만 사용됩니다. 공유 기능 등 일부 기능에서 결과 저장이 필요한 경우, 저장 데이터는 서비스 운영 목적에 필요한 기간 동안만 보관하고 이후 삭제할 수 있습니다.

5. 제3자 제공

이 사이트는 이용자의 개인정보를 제3자에게 판매하거나 임의로 제공하지 않습니다. 다만 Instagram 피드 표시, 이메일 발송, 사이트 호스팅 등 기능 제공을 위해 Meta, Netlify 등 외부 서비스의 API 또는 인프라를 사용할 수 있습니다.

6. 이용자의 요청

이용자는 본인과 관련된 데이터의 열람, 정정, 삭제를 요청할 수 있습니다. 요청이 접수되면 합리적인 범위에서 확인 후 처리합니다.

7. 문의
